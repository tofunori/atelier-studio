# Atelier Studio 1.9.0

Atelier Studio 1.9.0 rebuilds how a running turn reads in chat: tool calls now
group by step instead of scrolling past one row at a time, and the live status
lives in the thread rather than in a fixed strip above the composer. The LaTeX
review moves its Keep and Ignore decisions out of the text margin into a
floating card, and long dictations keep everything that was said.

## Chat activity groups by step

- Consecutive tool calls of the same kind collapse into a single summary row
  per step, with a cumulative duration and the calls one click away. A step of
  fewer than three calls stays as plain rows, since folding two lines hides
  more than it saves.
- The active step holds one live line that combines the summary with the
  current tool or turn status and a running timer. Finished calls are counted
  in the summary instead of stacking up, so a thirty-tool turn no longer fills
  three screens.
- The turn's outer fold always closes once the turn settles. A tool output left
  open during the turn keeps its state and reappears expanded when the fold is
  opened again.
- The live status moved into the thread flow. The dock that used to sit above
  the composer is gone, and the scroll-to-bottom pill carries the animated
  glyph and elapsed time while the reader is scrolled away.
- Tool rows drop the redundant status word and keep the check icon alone;
  failures retain a coloured label. Generic labels are replaced by what the
  call actually addressed: a file name, a search pattern, or the command.
- Errors stay visible when their step is folded, rather than being swallowed by
  the summary.

## LaTeX review without a margin

- Keep and Ignore decisions left the reserved 40 px gutter for a card that
  floats in the bottom-right corner of the editor pane, with block navigation,
  both decisions, and the ⌥↩ and ⌥⌫ shortcuts. Nothing is reserved in the text
  and nothing is added to the toolbar, which has no room to spare.
- Opening a passage now scrolls to it. Individual review does not collapse
  unchanged regions, so a change outside the viewport used to show a counter
  and an apparently untouched document.
- On a past intervention the card stays visible as read-only and offers a jump
  back to the latest one, instead of disappearing without explanation. Only the
  latest intervention can be decided, and the interface now says so.
- The latest intervention always compares against the live text. Editing the
  file after the agent's pass used to refuse the comparison outright, which
  made the diff look broken as soon as a single character was typed.
- Undo belongs to the decision that was just taken: it appears in the review
  card and clears itself after a few seconds, on navigation, and when the
  review closes, instead of leaving a button parked in the corner.

## Long-form dictation

- A long dictation no longer keeps only its final sentences. Speech recognition
  restarts its window on long input and reports hypotheses that cover recent
  audio only; those restarts are now detected and the previous window's text is
  committed before the new hypothesis is appended.
- The one-minute session cap applies only to server-based recognition, which
  Apple bounds. On-device recognition runs up to ten minutes.

## Composer, plugins and editors

- Composer menus share one presentation, so the model picker, knowledge picker
  and command menus open and read the same way.
- The Codex plugin and app catalogue is surfaced in the plugin panel, with the
  runtime routing and provider parsing that feed it.
- Gallery and editor polish: scrollbar treatment, gallery template, PDF viewer
  and review gutter measurement, plus the matching native mobile views.

## Repository

- The generated gallery cache is no longer tracked, and the repository root was
  cleaned of build artefacts.

## Notes

- assistant-ui was evaluated as a replacement for the chat surface and parked
  without shipping. The historical thread remains the chat surface; the
  evaluation is preserved on a branch rather than in the product.
