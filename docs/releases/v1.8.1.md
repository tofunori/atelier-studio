# Atelier Studio 1.8.1

Atelier Studio 1.8.1 makes long-running chat work resilient to delayed servers,
lost acknowledgements, restarts, and rapid navigation. It also completes the
redesign of LaTeX review and compilation tools.

## Reliable chat delivery and recovery

- Persist delivery receipts before provider execution and deduplicate repeated
  sends across concurrent connections and runtime restarts.
- Reconcile an unconfirmed send after reconnecting without automatically
  executing the provider turn again. Ambiguous post-crash outcomes are reported
  explicitly so users can verify them before retrying.
- Resume missed durable events from per-conversation cursors, with a safe full
  history fallback when a cursor is stale, unavailable, or too far behind.
- Protect live text from late history snapshots during rapid conversation
  switching, and correctly honor rewinds, deletions, and runtime generations.
- Retry busy or timed-out history, command, file, settings, usage, highlight,
  and automation reads independently with bounded backoff. Retries are
  coalesced, cancelled when their scope changes, and never resend a chat prompt.
- Keep newly created conversations visible immediately and retain composer
  drafts while navigating or recovering a connection.
- Preserve partial text after a user stops a response while removing the
  redundant stopped-duration label, interruption error, and warning icon.
- Keep normal delivery and response progress quiet; warnings remain reserved
  for actionable failures or uncertain delivery states.

## Conversation isolation and activity

- Split WebSocket routing and connection handling into explicit runtime modules
  so requests, replies, and failures stay attached to the correct conversation
  and project.
- Improve request identifiers and response boundaries for histories and
  catalogues, preventing an older response from overwriting another task.
- Preserve queue, steer, Stop, attachment, and draft behavior while recovery is
  active.
- Refine compact LaTeX attachment capsules in chat with filenames, line ranges,
  excerpt previews, and individual removal and undo. Multiple excerpts from the
  same file remain separate, and undo state is isolated by task.

## LaTeX review and compilation

- Refine the LaTeX toolbar with grouped Diff controls, polished icons, word
  wrap, and direct PDF access.
- Add a compact Accept All action that permanently completes review of applied
  changes without rewriting the current document. It clears pending review
  undo, disables itself, and reports zero remaining diffs while preserving
  conflicts and document history.
- Keep individual accept, reject, and undo actions available.
- Move compilation output into a compact resizable bottom panel with Problems
  and Log views, source-line links, copy, retry, and add-to-chat actions.
- Show compilation progress and status directly on the toolbar control and
  prevent overlapping compile requests.
- Place Accept and Reject controls on an opaque row above deleted text so they
  remain readable and reachable.
- Use CodeMirror-drawn selection in active Diff views and make review controls
  non-selectable, avoiding WebKit selection artifacts while scrolling without
  changing normal editing selection.

## Validation

- 656 sidecar tests, 225 runtime tests, and 27 durable-store tests.
- 143 chat regression tests plus 71 independent recovery and orchestration
  checks, including bounded retry, navigation cancellation, rewind, eviction,
  delayed snapshots, and silent Stop behavior.
- Gallery parity, 207 LaTeX diff tests, and the final three-test WebKit review
  suite, including persistent Accept All behavior after reload.
- A 10-minute synthetic endurance run completed 2,634 sends across 1, 5, and
  10 concurrent conversations with no lost events or duplicate executions in
  the independent journal audit.
- A forced connection loss during streaming recovered one complete response and
  one terminal event without resending the prompt.
- The final macOS app was rebuilt from the main checkout and verified through
  real conversation creation, send, response, navigation, draft preservation,
  and Stop interactions.

## Compatibility

The app targets macOS on Apple Silicon and packages its Rust backend and gallery
runtime. Claude Code CLI and Codex CLI remain external prerequisites for their
respective providers. Existing projects, conversations, and settings are
retained.
