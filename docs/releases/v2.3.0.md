# Atelier Studio 2.3.0

Atelier Studio 2.3.0 brings Word into the workspace. A `.docx` now opens in a
native editor beside the conversation, with its pages, tracked changes,
comments, equations, images and Excel charts as Word shows them, and the agent
can read, comment and revise it under your name. PDFs gain the same comment
margin and a corrected copy that any reader can open. The agent now sees the
figures of a Word document and the pages of a PDF, projects can be renamed,
and the project home becomes a grid of cards.

This release contains the full `main` history after **v2.2.1** through
**fde3989b** (pull requests #180 to #233).

## Highlights

### Writing: Word

- **Word editor** with real pages, line numbers, tracked changes and a review
  margin, built for long, heavily revised documents (#181, #186, #187).
- **Instant typing:** every keystroke, deletion, Enter and formatting gesture
  appears before the server answers; the document is kept open in memory with
  a write-ahead journal, so no edit is lost (#190, #202).
- **Sort tracked changes** by nature (substance, numbers and references,
  punctuation and spelling, spacing and formatting), accept all minor ones in
  one undoable step, and review the rest from the keyboard (A, R, arrows)
  (#202).
- **Equations** drawn with KaTeX and corrected in LaTeX, written back as a
  signed tracked change; rich paste and copy keep bold, italic, superscript,
  subscript and equations (#202).
- **Images and charts as in Word:** EMF and WMF pictures are rendered (upright,
  with Word's cropping), and charts pasted from Excel are redrawn from their
  cached values: scatter, line, bar, area and pie charts, log axes, trend lines
  with equation and R² (#209, #213).
- A PDF page pasted into Word for Mac (an EMF wrapping the PDF) is shown sharp
  instead of as a blurry preview (#233).
- **Comments:** edit your reply in place, send from the field, resolve a whole
  thread, open the comment margin from one button, and adjust its width
  (#188, #189, #195, #199, #204).
- **Annotate a passage** in Word and send it to the chat or turn it into a
  comment (#197); check one of your comments with Claude from an icon beside
  its text (#215).
- **Versions:** save a new version (`name_vN.docx`) without overwriting the one
  you received, reopen the received version, and keep a history that never
  discards anything (#196).
- **Open in Word:** a read-only copy opens in Microsoft Word to check its
  rendering, while Atelier stays the only writer of the original (#216).
- A commented document opens at 85 % with its comment cards side by side
  (#227).
- Word documents from folders attached to the project are listed with the
  project's documents (#205), and the gallery thumbnail of a `.docx` shows the
  top of its first page (#212).

### Claude in Word

- **Changes signed with your name:** tracked changes, comments and replies
  written by the agent carry your name, so a reviewer sees a single author;
  Atelier still marks them as proposed by Claude (#204, #209). A repair step
  re-signs older files (#208).
- The agent can **correct or withdraw its own comments** instead of adding a
  second one, and never touches the reviewer's (#219, #227).
- The agent drafts a reply inside the comment card (#188).
- An **unread dot** marks the comment threads that Claude wrote, answered or
  corrected and that you have not opened yet; it clears on click (#232).
- Stable paragraph references, join and split, equation replacement and rich
  insertion are available to the agent as tracked edits (#202, #230).

### Writing: LaTeX and review

- **Import a reviewer's Word feedback into LaTeX:** comments from the returned
  `.docx` are placed in the matching `.tex` passages, across every file of the
  project, and the reviewer's tracked changes become proposals you accept or
  decline (#182, #191).
- Reviewer annotations are cleaner: a number in the margin, a bubble and a
  single button (#194).
- **Revise your LaTeX from Claude (prototype):** an Atelier connector shows a
  `.tex` file inside Claude, where you select passages and receive proposed
  revisions that only a click applies; Atelier launches the connector (#180).

### PDF

- **Comment a PDF like a Word document:** the Annotations column becomes the
  same comment margin, with replies, resolve and delete; comments already
  written in the file by Acrobat or Preview are picked up once (#225).
- **Corrected copy:** `name_corrigé.pdf` is written next to the original, with
  the comments printed in a widened margin and real PDF annotations, readable
  in any PDF reader. The original never changes (#225).
- PDFs whose names contain spaces, brackets or parentheses open again (#222).

### The agent sees more

- **Figures of a `.docx`:** the agent looks at the document's images and
  charts, rendered as on the Word surface, instead of guessing from their
  alternative text (#229, #230).
- **Pages of a PDF:** the agent can view chosen pages as images (#229).
- The agent is told when its tools have been updated, and a refused action
  lists the available ones (#230).

### Projects and chat

- **Rename a project** without touching its folder, from the home card, the
  project settings or the top bar menu (#231).
- **Project home as a grid** of square cards (#217); "New project" makes the
  chosen folder the project (#207).
- **Figure version history** as a strip under each figure in the gallery
  (#185).
- **Annotated quotes** in the chat are lighter: the quoted passage in muted
  text with a thin elbow line to your reply, always on whole words (#228).
- Chat replies are set in a reading column (#201), and Word context in the
  message box is quieter (#200).
- Compact bar: the active project's threads under its chip, a usage gauge
  above the settings button, and a clickable empty area (#184).

### Interface

- Document tabs shrink together instead of overflowing (#183).
- The message composer folds instead of overlapping in a narrow chat (#192).
- Panel resizing is smooth (#199).
- File-type icons: one shape per type, with a muted tint for five of them
  (#223).
- One panel icon in the Word toolbar, arranged in two groups (#210).

### Reliability and CI

- History test for a moved document made reliable (#221).
- Steadier tests for the project menu and the Word server refusal (#227,
  #231).

## Compatibility

The artifact targets **macOS on Apple Silicon (arm64)** and bundles the Rust
backend and the gallery runtime. Claude Code CLI and Codex CLI remain external
prerequisites for their providers. The Python kernel needs pixi. Microsoft
Word is optional: it is only used by "Open in Word".
