# Atelier Studio 2.4.0

Atelier Studio 2.4.0 opens Jupyter notebooks in the workspace and runs on
Linux. A `.ipynb` now opens beside the conversation with its own kernel, and
the agent can read, run and propose cells. Linux builds (`.deb` and AppImage,
x86_64 and arm64) are attached to the release. Google's Antigravity CLI joins
the chat providers. Word gains figure, equation and text-box editing by hand
and by the agent, figure annotation becomes durable notes with versions, and
specialists in the chat collapse into a single signed row.

This release contains the full `main` history after **v2.3.0** through
**e1b4bf8a** (pull requests #235 to #285).

## Highlights

### Jupyter notebooks

- **Notebook editor** for `.ipynb` files, with a native ZeroMQ (ZMTP 3.x)
  kernel client written in Rust: no Jupyter server is needed (#277).
- The agent sees which cells come before and after the one it works on, and
  proposes cells that you accept and run in one step (#277).
- **Robust kernel sessions:** long-running cells, `input()`, a dead kernel
  restarted cleanly, and changes made to the file by another program picked
  up; a backup copy of unsaved changes is offered when the notebook reopens
  (#279).
- **End-to-end tested editor:** cells edit on click, show clear running and
  error states, and a failing cell can be sent to the chat with "Fix with the
  chat" (#282).
- Notebooks appear in the gallery with their first figure, under a "Jupyter"
  format filter, and open in the notebook editor (#282).
- **Notebooks without `ipykernel`:** on Atelier's fallback kernel,
  `display()`, `IPython.display`, rich outputs (`_repr_html_` and friends),
  inline Matplotlib figures and common magics now behave as in Jupyter
  (#285).
- A notebook cell has the same selection bubble as a Python file: highlighter
  with its colors and notes, stored beside the notebook without changing the
  `.ipynb` (#285).

### Linux

- **Native Linux port:** the app, terminal and LaTeX work on Linux; OpenCode
  is set up out of the box (#278).
- **Turnkey Python and Jupyter:** when the machine has no pixi, Atelier
  downloads a pinned, checksum-verified pixi and prepares an environment with
  `ipykernel`, NumPy, pandas, Matplotlib and SciPy (#281).
- The `.deb` depends on `curl`, `git` and `xdg-utils`; a TeX Live installed
  with the official installer is found outside the app's `PATH`, on Linux and
  macOS (#281).
- Linux packages (`.deb` and AppImage, x86_64 and arm64) are built by the
  release workflow and added to the release without blocking the macOS
  publication (#278).
- A new `linux` CI job runs the Rust tests on Ubuntu with WebKitGTK on every
  pull request (#278).

### Providers

- **Antigravity (`agy acp`)** is available as a chat provider (#276).

### Writing: Word

- **Figures by hand and by the agent:** move, resize and use a figure's menu;
  the agent can replace, delete or move a figure as a tracked change, even when
  it shares its run, is commented or sits at the top of a page (#253, #254,
  #255).
- **Equations:** the agent reads, corrects and adds equations as tracked
  changes; the equation box is quieter, with a "Line" variant (#250, #266).
- **Text boxes and shapes** placed on the page are shown on the Word surface
  and visible to the agent (#239).
- **Live Zotero citations** in the Word surface, from a palette at the cursor
  or by the agent (#242).
- **Reviewer summary:** the state of each reviewer comment since the received
  version (#271).
- Colored ribbons on comments to find where you left off (#243), the open
  comment stands out while the others recede, in Word and PDF (#259), and the
  text of a bubble can be annotated like the page (#237).
- Delete a single reply or a whole thread, with a full-width reply field
  (#248); a draft stop button and a cleaner comment card (#244); ✕ and ✓ on
  your own edits too (#245).
- Text and figures no longer overflow their sheets after an acceptance (#265),
  and the margin bar of an edited paragraph stops at each sheet (#270).

### Figures

- **Figure annotation:** sharp marks, a palette above the figure and keyboard
  shortcuts; a Notes panel with each note's position and crop; durable notes
  tied to the figure version, with states, Resend and Compare (#260, #261,
  #262).
- **Figure viewer:** a bottom strip with Versions and Notes tabs (#264), notes
  sent as a list and versions folded into a stack (#275), and a smooth A/B
  comparison slider (#268).
- Figures saved from the chat stack as versions instead of overwriting each
  other (#263).
- **Gallery by folder:** a "Folder" button shows the whole content of a folder
  (#267).

### Chat

- A specialist is a single signed row in the main thread, with its compute
  card underneath (#272, #274); the compute card can float (#273).
- Calm tool rows, red only when the work stops (#236), and three animated dots
  for "Thinking…" (#269).
- **Send to Atelier** from the Finder and from selected text (#235).

### Interface

- **Graphite theme:** a lighter dark frame around black content (#251, #252).
- Floating panels with 12 px gutters, a drop shadow and a single outline
  (#256).
- A "Code background" slider in the dark theme settings (#285).
- Compact bar: sub-threads have their own line under their conversation
  (#246).

### Reliability

- A keystroke, a comment, a resolve or a reply is no longer lost when the
  agent edits the same paragraph at the same time (#240, #241).
- A resolved thread stays resolved (#247); the Track changes switch no longer
  overflows its label (#249).
- The first-kernel test uses the real Python interpreter instead of Apple's
  `python3` launcher on macOS (#284).
- Nothing personal is left in the defaults: Word instructions, default
  provider and the `.fig_thumbs` warning (#257).

## Compatibility

The macOS artifact targets **macOS on Apple Silicon (arm64)** and bundles the
Rust backend and the gallery runtime. Linux packages target Ubuntu 22.04 or
later with WebKitGTK 4.1, on x86_64 and arm64. Claude Code CLI, Codex CLI and
Antigravity CLI remain external prerequisites for their providers. The Python
kernel and Jupyter notebooks use a pixi environment, which Atelier downloads
and prepares when none is installed; an existing `.venv`, Conda or system
Python with `ipykernel` also works. Microsoft Word is
optional: it is only used by "Open in Word".
