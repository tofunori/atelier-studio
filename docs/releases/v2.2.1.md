# Atelier Studio 2.2.1

Atelier Studio 2.2.1 gathers the work merged since 2.2.0: a richer LaTeX
editor with live compilation and a refined diff, a project History tab, the
same Annotations column in LaTeX and in the compiled PDF, Claude Code's "Auto"
permission mode, a Results screen and a scientific reviewer, a single Python
environment managed by pixi, and a polish pass that brings every icon into one
family. The native iPhone app also moves forward (editorial direction), but
this release does not publish an iOS application.

This release contains the full `main` history after **v2.2.0** through
**cfc15a9c** (pull requests #157 to #178).

## Highlights

### Writing: LaTeX

- **Manuscript editor** with a PDF reading table (#160).
- **Refined diff**, line by line then word by word, without orange (#160).
- **Typographic reading mode** (#160).
- **Live compilation:** the current pass and page update as you write, and the
  last valid PDF stays on screen (#160).
- **Same Annotations column** in the LaTeX editor and in the compiled PDF tab
  (#165).
- **Annotate = save:** a note card and a selection bar replace the separate
  save step (#169).

### Project

- **History tab** for the project: the changes made over time, in one place
  (#162).
- **Results screen:** a library of what the project has produced (figures,
  tables, PDFs), with their origin, the environment that made them and a way
  to replay them (#174).

### Chat

- **"Auto" permission mode** of Claude Code in the chat lock menu (#173).
- **Scientific reviewer:** a turn can be checked for scientific content, with
  a foldable "Review" line under the reviewed turn (#174).
- **Fable 5.2** replaces Fable 5.1 in the Claude model picker; earlier choices
  are migrated (#172), and the Claude model list is up to date (#157).
- The agent can place its own notes in `.tex` files and PDFs (#157).
- Live context eye: also sees the figure, the `.docx`, the article and the web
  page (#157).
- Sending a message is smoother: the message flies from the composer to its
  bubble (#166).
- Permission receipts are folded into the action row, and the tool block is
  tighter (#176).
- Threads are listed under their conversation, with their state (#171).

### Python kernel and computation

- The agent sees the figures it produces, and the kernel's memory and CPU use
  (#174).
- **One "atelier" environment managed by pixi** instead of several conda
  environments (#174).
- A Slurm submission whose answer is lost is found again on the cluster
  (#174).

### Interface

- **Top bar with "set" tabs**, drawn as a single piece (#161, #168).
- **One icon family** (Lucide) at 12 and 14 px (#177).
- Centered empty screen, chat welcome, code blocks and message field reworked
  (#175).
- Thread margin with plain grey strokes, visible only while scrolling (#159).
- PDF thumbnails are rendered by PDFium: no more qlmanage icon in the Dock at
  each compilation (#164).

### Fixes and security

- SVG editor: the v2 retouch layer is now saved and read back (#174).
- Gallery: a foreign `Host` header is no longer served (DNS rebinding) (#174).
- iPhone gateway: Tailscale CLI receives TERM, and a failure is logged (#163).

### iPhone app (source only)

- Editorial direction on every surface (#158).

### Reliability and CI

- History test anchored at local noon, so it passes right after midnight
  (#170).
- Steadier tests for the Reading view and the HTTP smoke suite (#178).

## Compatibility

The artifact targets **macOS on Apple Silicon (arm64)** and bundles the Rust
backend and the gallery runtime. Claude Code CLI and Codex CLI remain external
prerequisites for their providers. The Python kernel needs pixi. The Crossref
check needs network access.
