# Atelier Studio 2.0.0

Atelier Studio 2.0.0 expands PDF annotation workflows, connects the Ragdoc corpus
to the research workspace, brings more Claude CLI interactions into the chat,
and reduces the cost of opening histories, typing and keeping document tabs
open. The repository’s maintained JavaScript sources move to TypeScript 7.

This release includes every development commit after **v1.9.3** through
**251fa2b6**, plus the release preparation described below. The complete
55-commit ledger includes feature, fix, refactoring, test, documentation,
artifact-refresh and merge commits; merge entries describe integration rather
than counting the same feature twice.

## Highlights

- **PDF annotations:** personal notes separate from chat messages; shared
  annotation access for desktop and mobile code; continuous highlight geometry;
  six colors; editable highlight/underline style; Zotero reading markers; and
  a toolbar action for attaching the current PDF to a chat draft.
- **Annotations MCP companion:** cross-article search, article-text reading,
  exact passage highlighting, and controlled editing/removal of assistant-owned
  highlights. This is a separate Rust companion server in the repository, not
  an automatically configured Claude Desktop connection.
- **Ragdoc:** a persistent import/review workspace, duplicate checks, Zotero
  selection, canonical passage retrieval and explicit verification before an
  import is reported as indexed. Existing GBrain references remain readable.
- **Claude and Codex:** structured permissions, questions and plan choices;
  stronger turn completion and Stop handling; task, hook and subagent events;
  Opus 5.5 with 1M context as the inherited default; and read-only Codex goal
  retrieval without starting a session.
- **Performance and maintenance:** hidden-tab polling pauses, less application
  rendering during typing and heartbeats, cheaper long-history replay, smaller
  entry-bundle loading, decomposed application/router modules, and a reproducible
  TypeScript source-to-browser build.

## Compatibility and distribution

The desktop artifact targets **macOS on Apple Silicon (arm64)** and bundles the
Rust backend and gallery runtime. Claude Code CLI and Codex CLI remain external
prerequisites for their respective providers. Optional Ragdoc imports require
the configured Ragdoc environment, Python 3 and SSH access; the annotations MCP
companion requires separate setup. Native-mobile source changes are documented
in the ledger but this release does not publish an iOS application.

For contributors, scripts require **Node.js 22.18 or later**. Historical
JavaScript surfaces are checked with dedicated TypeScript configurations;
this release does **not** claim that all of them use strict typing. Vendor
libraries and executable browser outputs remain JavaScript.

The current GitHub packaging configuration uses an ad-hoc macOS signature and
does not perform Apple notarization. This release does not change that
existing distribution limitation.

## Release preparation

- Aligns the npm package, npm lockfile, Tauri configuration, Rust package and
  Rust lockfile on **2.0.0**.
- Repairs the website lockfile for a clean npm 10 installation: TypeScript
  5.9.3 satisfies the `tsconfck` peer requirement under `vite-tsconfig-paths`,
  separately from the website’s TypeScript 6 compatibility alias and native
  TypeScript 7 checker.
- Supplies these English release notes to the existing release workflow. The
  workflow installs dependencies, stages runtime resources, runs verification
  and gallery E2E checks, builds the macOS artifacts, verifies the packaged
  signature and Rust executables, then publishes the release.
- Local uncommitted work is excluded from the tag and distributed artifacts.
