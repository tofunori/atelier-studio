# Atelier Studio 2.4.1

Atelier Studio 2.4.1 is the first version that updates itself. When a new
release is published, a card says "Atelier X is available" and one click
downloads it, checks its signature, installs it and restarts, on macOS, with
the Linux AppImage and with the `.deb` package. The release also brings a
guided tour on a small sample project, annotation of notebook figures sent to
the chat, plain text files and a set of Linux fixes.

This release contains the full `main` history after **v2.4.0** through
**241ab56b** (pull requests #286 to #291).

## Highlights

### In-app updates

- **Update card:** Atelier checks the latest release shortly after launch and
  every six hours. A card shows the new version with "Update" and "Later"
  ("Later" hides that version for 24 hours); a system notification appears when
  the window is in the background (#289).
- **One click:** the package is downloaded with a progress bar, its signature
  is verified against the key built into Atelier, then it is installed and the
  app restarts. Unsaved documents go through the same prompt as Quit (#289).
- **Per platform:** on macOS the app bundle is replaced; the AppImage is
  rewritten in place; the `.deb` is installed with `pkexec dpkg -i`, so Linux
  asks for the user's password. If installing fails, the card offers "Retry"
  and "Download" (the release page) (#289).
- **Settings › General › Updates:** the current version, a "Check now" button
  and a "Check automatically" switch (#289).
- The release workflow now signs the macOS archive, the AppImages and the
  `.deb` packages, and publishes a `latest.json` manifest with the release
  (#289).

**Note:** versions 2.4.0 and earlier do not have the updater. Install 2.4.1
by hand once (`.dmg`, AppImage or `.deb` from this page); later versions then
arrive in the app.

### Getting started

- **Guided tour:** on first launch, an invitation offers a six-stop tour
  (projects, chat, gallery, figure annotation, Word/LaTeX/notebooks,
  surfaces). It opens **Glacier-Exemple**, a small sample project shipped with
  the app and written to `~/Documents/Atelier/Glacier-Exemple`, and prepares
  each screen. The tour can be replayed from the command palette and from
  Settings › Environment (#287).

### Notebooks

- **Annotate a notebook figure** and send it to the chat, like any other
  figure (#286).
- More robust Jupyter engine: long cells are no longer cut off after 15
  seconds, `input()` is supported, a dead kernel is detected and changes made
  to the notebook outside Atelier are picked up (#286).

### Text files and Linux

- **Plain text files:** `.txt` files appear in the gallery and its format
  filter and open in the editor. Atelier is offered in "Open with" for text
  files, in the Finder on macOS and in the file manager on Linux (#291, based
  on #288 by Alex).
- New `atelier` command on Linux, installed by the `.deb`: `atelier ~/thesis`
  opens a folder as a project and `atelier notes.txt` opens a file, also in an
  instance that is already running (#291).
- SyncTeX: a click in the PDF on text that comes from an `\input` file opens
  that file at the right line (#291).
- Smoother rendering on Mesa GPUs (AMD, Intel): the WebKitGTK DMA-BUF
  workaround is only applied on NVIDIA and in virtual machines (#291).
- The iPhone gateway is no longer started outside macOS, where it failed at
  every launch (#291).

## Compatibility

The macOS artifact targets **macOS on Apple Silicon (arm64)** and bundles the
Rust backend and the gallery runtime. Linux packages target Ubuntu 22.04 or
later with WebKitGTK 4.1, on x86_64 and arm64. Claude Code CLI, Codex CLI and
Antigravity CLI remain external prerequisites for their providers. The Python
kernel and Jupyter notebooks use a pixi environment, which Atelier downloads
and prepares when none is installed; an existing `.venv`, Conda or system
Python with `ipykernel` also works. Microsoft Word is optional: it is only
used by "Open in Word".
