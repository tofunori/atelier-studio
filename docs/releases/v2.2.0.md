# Atelier Studio 2.2.0

Atelier Studio 2.2.0 gathers the work done since 2.1.0: a projects home with
"Resume", a chat that knows what you are looking at, annotation rounds with the
agent in LaTeX and PDF, Crossref checking of the `.bib` file, a cleaner and
customizable LaTeX toolbar, a unified side column, and a broad interface polish
pass ending with a darker "anthracite" ground. The native iPhone app also moves
forward (redesigned chat, folded tabs), but this release does not publish an
iOS application.

This release contains the full `main` history after **v2.1.0** through
**6946aa55** (pull requests #103 to #155).

## Highlights

### Projects

- **Projects screen** on the desktop, with a menu on the project name (#138).
- **Projects home with "Resume":** the last work of each project is one click
  away, with a way back (#152).

### Chat

- **Live context:** what you are looking at (file, page, selection) travels
  with each message (#137); a selection is no longer sent on its own (#143);
  an eye in the bottom bar shows and controls that context (#149).
- **Agent questions card:** one question at a time, numbered rows (#114).
- **Compact command approval card**, folding into a single line (#148).
- Tool activity on one quiet line (#127); revised passages shown as a
  monochrome diff (#126).
- Attachments shown as "article" cards (#134); markdown tables fold to the
  panel width and become cards when it is too narrow (#113); no horizontal
  scrollbar under the "changed files" card (#128).
- Chat box menus brought into a single family (#155).
- Conversation bar: two-line rows with the provider icon before the title
  (#135).

### Writing: LaTeX

- **Cleaner, customizable toolbar** (#146), with the References and Add to
  chat icons aligned (#142).
- **Annotation rounds with the agent**, in a soft color (#139); the agent can
  annotate `.tex` files and PDFs directly (#150), and a discreet capsule
  gathers the annotations (#151).
- **Crossref check of the `.bib` file** from the editor (#141).
- Word count and a "To do" panel in a bottom bar (#140).
- Reading mode: the column follows the panel, with a full-width option (#132).
- The folded diff stays fluid on large files (#145).

### PDF, gallery and computation

- PDF reader: the white bar of embedded frames is hidden from the first load
  (#112, #117); a dragged note or stamp survives a resync (#124).
- Gallery: the annotation tool stays available in full screen, and the top bar
  icon closes the open figure (#105).
- Persistent Python kernel: quieter cells and a single scroll (#120).
- Mac computations: the probe waits for the final state when the child process
  has just finished, and rereads a manifest caught mid-rewrite (#124, #145).

### Interface

- **Unified side column** (variant A) for the sidebar and conversations (#144).
- Top bar: a Gallery button and a launcher instead of nine icons (#123); the
  pane menu opens on right click (#129).
- Tabs can be reordered by dragging them in the top strip (#125).
- Specialist menu simplified (#118).
- Polish batches 3 to 5: raised surfaces, icons, token colors, empty, error
  and offline states, editors and viewers (#103, #104, #106, #107 to #110);
  raised panels and statuses without colored labels (#147).
- Darker "anthracite" ground in the dark theme (#154).

### iPhone app (source only)

- Redesigned chat without a tab bar, with opaque header and footer (#131);
  tabs folded next to the composer (#122); no more black raw-text block when
  returning to the app (#133).

### Reliability and CI

- Release notes for 2.1.0 published in English, and menu row height tests
  tolerant of sub-pixel rounding (#105, #136).
- Flaky tests fixed in the PDF tools and top bar suites (#116, #124).
- Gallery UI bundle regenerated from `main` (#111, #119).

## Compatibility

The artifact targets **macOS on Apple Silicon (arm64)** and bundles the Rust
backend and the gallery runtime. Claude Code CLI and Codex CLI remain external
prerequisites for their providers. The Python kernel needs a local Python 3.
The Crossref check needs network access.
